# Triage 标签

工程技能使用五个规范分拣角色。本文件把这些角色映射到本仓库 issue tracker 上的实际标签字符串。

| 技能中的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估这条 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已完整，可以由无人值守的 agent 接手 |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不会处理 |

技能提到某个角色时（例如 "apply the AFK-ready triage label"），使用本表「本仓库标签」列中的字符串。

若实际用词不同，只改「本仓库标签」列。
